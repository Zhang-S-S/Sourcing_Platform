# 墨西哥企业资料动态接入

日期：2026-11-16。适用于 React 项目当前已接入的墨西哥出口检索。

## 通用关联流程

每次搜索、翻页或读取详情后，根据该批实际返回的贸易记录编号，在后端重新读取其供方编号。对同批供方去重，批量关联企业名录，再将结果按贸易记录编号返回给前端。实现不包含任何特定企业名称、企业编号、电话、网站或员工人数。

```text
当前页的 panjivaMXExport.panjivaRecordId
 → 该记录的 shpPanjivaId
 → panjivaCompanyCrossRef.identifierValue
    （identifierTypeId=21001，activeFlag=1，有效期检查）
 → panjivaCompanyCrossRef.companyId
 → ciqCompany.companyId
 → ciqCompanyData.companyId
```

关联类型 21001 经本环境数据抽查确认用于该映射；代码按此已核实类型匹配。供方编号与企业主键不是同一编号。优先使用唯一的有效主关联；没有主关联时要求有效关联唯一。关联冲突不自动合并；企业国家须通过 ciqCountryGeo.isoCountry2 核实为 MX。没有有效关联时，不按名称相似度猜测电话号码或规模。

## 字段映射

| 页面字段 | 实际数据位置 | 处理 |
| --- | --- | --- |
| 电话 | ciqCompany.officePhoneValue、otherPhoneValue | 去除空值、合并去重，卡片、表格及详情展示具体值 |
| 网站 | ciqCompany.webpage | 展示具体名录网站文本，不自动声称已独立核验为官网 |
| 员工数 | ciqCompanyData.dataValue，companyDataTypeId=35 | 返回实际非负数值及规模区间，缺失与0分开 |
| 成立年 | ciqCompany.yearFounded | 基础信息展示实际值 |
| 行业 | ciqCompany.simpleIndustryId → ciqSimpleIndustry | 展示源行业名称，不推断制造商身份 |
| 企业状态 | ciqCompany.companyStatusTypeId → ciqCompanyStatusType | 明确属于企业名录状态，不当作登记核验 |

没有查到的 WhatsApp、邮箱、联系人保持缺失，不能由电话号码推断 WhatsApp。源名录员工字段没有时点列，当前展示不宣称为实时员工人数。

## 接口与页面

- `GET /api/mexico/exports/profiles?recordIds=...`：补充一批贸易记录的企业资料，最多50条，要求已登录。
- `GET /api/mexico/exports/statistics?recordIds=...&country=MX&hs=...&keyword=...&company=...&refinedHs=...`：按相同搜索条件及该批供方编号执行全期汇总；不带页面游标，按完整匹配范围统计。
- 搜索首屏、资料补充、贸易统计分别加载。统计慢或失败不阻塞已返回的线索、电话、网站和员工资料。
- 卡片、表格及详情使用一致的补充结果。切换页面后，旧请求不得覆盖新页面；历史恢复会重新订阅未完成的补充请求。
- 浏览器与后端缓存均限量并保留10分钟，成功后复用；失败不缓存为缺失数据。后端贸易汇总最多单并发。

前端区分“读取中”“读取失败”“尚未关联”“关联冲突”和“已关联但字段为空”。重新搜索可重试失败项。

## 贸易汇总的口径与实测限制

记录数按当前国家、产品词、HS、企业名称细筛和同一来源供方编号，读取全部匹配贸易记录。它不等于订单数，不跨不同供方编号做未经核实的企业归一。

当前未取得确认连续覆盖的元数据及近期窗口，因此成功结果标注“全期匹配”，最早/最晚值标注“记录日期范围”，不把两端日期之间声称为完整覆盖。此功能不发布近期排名、连续覆盖或未经核定的金额汇总。

源表缺少供方/日期/HS二级索引。对真实大表的完整汇总抽查在180秒内未完成，故本次不宣称已验证全期汇总性能或近期指标。实现已提供独立查询、等待和失败状态；统计语句不设执行时限，不为填数字而截取样本。统计连接会临时取消客户端socket等待上限，并在归还连接池前恢复；目录查询保留30秒语句时限。

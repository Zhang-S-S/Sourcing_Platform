# 页面导航与浏览器历史

原实现只修改 Vue 状态或原型 DOM，浏览器始终认为用户停留在同一个页面。因此点浏览器后退会返回进入系统前的新标签页。本次把实际页面切换接入 History API，以哈希地址兼容当前 Vite 和本地启动方式，无需改变后端或部署路由。

## 当前行为

- 登录、注册及登录方式切换有对应地址；成功登录新增业务页历史，保留登录页。浏览器后退可回到登录表单，前进可回业务页；密码/验证码清空，返回登录页不自动退出会话。退出/会话失效后受保护页面仍返回登录。
- 已登录用户直接进入系统或旧版入口缺少登录历史时，会补一个登录入口；刷新保留已有前驱标记，不反复插入登录页。
- 供应商发现、搜索条件、A/B/C 通道、卡片/表格、结果细筛、分页、真实贸易详情、收藏/对比和原型企业详情都能进入历史。
- 浏览器后退/前进恢复原页面。真实详情的“返回搜索结果”优先返回已有列表历史，不重复创建列表入口；直接打开详情地址时可回退到相同条件的列表。
- 地址保存已提交的产品、HS、国家、名称筛选、HS 细筛、通道、展示方式、页大小及游标。刷新已登录的详情或搜索地址可重新加载对应内容。
- 后退优先恢复当前标签页中已有结果，避免每次后退重新扫描远程表；查询中的同一请求复用，后返回的旧请求不覆盖已恢复的新页面。
- 缓存最多保留 100 个历史页面的 UI 快照及 30 个搜索响应；超出内存范围或刷新后按地址重新读取。原型数据仍为静态演示，刷新不代表保存了收藏/评价业务数据。
- 刷新深页后没有之前的完整游标链时，“上一页”返回可确定的第一页；常规同一标签页连续翻页与浏览器后退保持原页。
- 滚动位置随历史页面恢复。点击同一地址不重复堆叠历史。

只有地址与随机导航键进入浏览器历史；账号密码、验证码和贸易结果不写入 history.state、localStorage 或 sessionStorage。页面快照只在当前标签页运行内存中保存，退出或切换用户时清除。客户端恢复不代替服务端鉴权，所有数据接口继续校验登录状态。

系统不会强行拦截用户离开网站：在当前标签页的第一个系统页面上，没有更早的系统内历史时，浏览器后退仍可返回此前的外部页面或新标签页。

## 代码与验证

- `frontend/src/navigation.js`：地址解析、历史记录、内存快照和返回事件。
- `App.vue`：认证入口与登录状态保护。
- `Workspace.vue`、`MexicoLeads.vue`：业务导航和列表/详情状态恢复。
- `LegacyWorkspace.vue`、`prototype/workspace.js`：保留原型页面并接入相同导航。
- `scripts/import-prototype.mjs`：重新导入原型时保留上述历史集成。

前端目录运行 `node --test tests/navigation.test.mjs`，共 8 项测试，覆盖地址往返、后退/前进、搜索快照隔离、重复/替换导航、详情返回、私有缓存清除、登录页前驱保留及旧入口补齐；`npm run build` 验证构建。实际浏览器另验证登录后后退/前进、刷新、密码/验证码清空和退出后访问保护，以及之前的 HS 8544 第二页等业务导航。

本次没有修改数据库、SQL 搜索、并发/限流或已取消的搜索超时设置。

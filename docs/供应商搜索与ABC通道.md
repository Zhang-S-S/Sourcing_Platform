# 供应商搜索与 A/B/C 通道

依据甲方 PRD P0-06、P0-07、P0-08 恢复页面结构。本次实现全表条件检索与预留通道，不代表整个 P0 已完成。

2026-11-08 补充：按用户要求暂时关闭搜索后端 12 秒及前端 15 秒超时；仅影响搜索，其他请求、分页、限流、并发和只读设置保持原样。以下实测中的 12 秒超时为关闭前记录。

## 页面与规则

- 产品关键词、HS Code、国家、搜索按钮恢复至原版位置。国家首次为空，仅墨西哥可选。
- 产品/HS 至少一项；同时填写使用 AND，命中同一条贸易记录。关键词按商品原文包含查询；不擅自翻译或扩展产品事实。
- HS 按字符串保留前导零，支持 2/4/6/8/10 位数字前缀输入。源字段多编码在数字边界匹配，忽略编码中的点号；不在另一编码中间命中。编码版本/字典有效性尚未核定，不宣称自动跨版本转换。
- A 本地·贸易线索：墨西哥出口记录且供方国家明确为 Mexico/México/MX/MEX/墨西哥；国家不明确的记录不强塞入 A。
- B 本地·名录、C 境外·贸易线索保留位置、切换和说明，显示“待接入”，不显示虚构的 0 家或演示企业。切换保留条件和 A 结果，不触发额外查询。
- 企业名称模糊筛选在服务器执行，不仅筛当前页。为避免每次按键触发大表查询，输入后按回车或点“筛选”。
- 高级筛选为抽屉，HS 细筛应用后生效；关闭/取消丢弃未应用编辑；重置只改草稿，应用后提交。细筛不得扩大顶部 HS 范围。来源固定海关；属性、联系、规模、供货量缺真实数据/统计口径，置灰说明。
- 卡片/表格使用同一页结果。翻页保留已提交的关键词、HS、国家、名称和 HS 细筛；编辑顶部草稿不改变已提交搜索。新搜索、细筛或每页条数变化回第一页。详情返回保持原结果和视图。

## 搜索接口

`GET /api/mexico/exports/search?country=MX&hs=8544&keyword=cable&company=&refinedHs=&limit=20&before=...`

`keyword`、`hs` 至少一项；`country=MX` 必填；`company`、`refinedHs` 可空；`limit` 为 1～50；`before` 为上次响应的 `nextCursor`，首屏省略。

返回 `items / hasNext / nextCursor / pageSize / order`。最多读 51 条以判断下一页；不计算 COUNT、不返回全库 total、不做 OFFSET。分页范围是全表符合条件的记录，未使用本地缓存/当前页/最近若干条作为检索全集。源表不变时按记录编号游标连续翻页；外部并发更新不具备版本化快照保证。

所有表、字段、排序及条件片段均由代码固定；用户值通过 JDBC 参数绑定。LIKE 的 `%`、`_`、`[`、`~` 按字面转义，不能注入 SQL 或用通配符意外放大条件。原文与名称查询使用大小写/重音不敏感排序规则；Unicode NFKC 规范化输入。没有已审核跨语词典，因此中文不会自动翻译成西语/英语。

查询源只执行 SELECT。账号注册/登录仍在本地 MySQL；本次没有给甲方新建表、缓存、索引、视图、存储过程或修改权限。

## 错误与负载限制

- 401 未登录，403 停用/禁止的写请求，400 非法参数。
- 504 查询超时：明确“不是没有匹配记录”；503 数据源故障；均不返回成功空结果或演示数据。
- 搜索每用户每分钟最多 12 次，实例中同时只执行一条全表搜索；忙碌或超限返回 429。浏览/详情仍按既有限流保护。
- 搜索的 JDBC 查询超时为 0（不限制执行时间），浏览器搜索请求不设置等待计时器。其他浏览/详情仍保留 12 秒查询超时，其他前端请求仍为 15 秒；数据库连接建立和外部服务器本身的限制未改变。

## 实测与尚未完成的 PRD 要求

2026-11-08：真实 HS `8544` 每页两条的首屏、下一页成功且无重复，首屏 HTTP 单次约 23 ms（仅本次测量）；浏览器每页 20 条亦返回真实线索。`cable` + `8544` 组合实际触发 12 秒超时，页面错误与重试入口正确。表目前只有记录编号聚集主键，未看到 HS/描述/名称索引；只读诊断限制 MAXDOP 1 也超时。不能由某个快查询保证所有条件均快。

结果当前粒度仍是贸易记录，同一供方可能重复；不把本页记录数当企业总数。不提供综合排名、近期记录数或贸易量排序，两个原版排序项以待核定禁用状态保留。尚未完成企业归一及同次检索企业唯一、用户检索上下文持久化、来源许可字段裁剪、角色/国家授权模型、审核跨语词典、B/C 数据、真实收藏与对比。当前页面移除了源记录 ID 展示，但基础 API 的原 DTO 仍需在许可确认后进一步裁剪。

后续提高性能应由甲方核定搜索索引、检索视图/接口或独立检索服务；本项目不会自行修改甲方数据库。若许可本地建立完整检索库，应单独约定同步范围、更新机制和数据许可，不以少量样本替代全库检索。

# 墨西哥出口贸易线索

## 已实现流程

登录 → 供应商发现 → 输入产品/HS 并选择墨西哥 → A 本地贸易线索全表条件查询 → 卡片/表格切换 → 保留条件的主键游标翻页 → 查看记录详情 → 返回原搜索页。B/C 保留入口，暂不接入数据。

搜索接口与最新边界见 [供应商搜索与ABC通道](供应商搜索与ABC通道.md)。下列三个 SQL 为保留的基础浏览/详情接口；搜索使用附加参数化条件的 SELECT。

本功能仅读取甲方 SQL Server 的 `dbo.panjivaMXExport`。没有对甲方执行 INSERT、UPDATE、DELETE、建表、建索引、建视图或存储过程修改。

## 数据与展示口径

- 每张卡片/每一行是一条贸易记录。同一供方可重复出现，不进行全库企业去重。
- “墨西哥”表示墨西哥出口数据集的范围，供方国家字段按记录原值展示，不强制改写成墨西哥。
- 按 `panjivaRecordId` 降序，而不是按贸易日期排序，不称为“最近日期”或企业排名。
- 日期来自 `shpmtDate`，页面标为“贸易日期（源字段，语义待核定）”；不未经核对直接认定装运/付款日期，不推断完整覆盖区间。
- 数量与单位分别来自 `shpmtQuantity`、`shpmtUnit`；毛重为 `grossWeightKg`。
- 货值为源字段 `valueOfGoodsItemCIFUSD`，按源字段 CIF/USD 口径展示，不计算公司累计货值或自行换汇。
- 供方编号来自 `shpPanjivaId`，不直接作为 `ciqCompany.companyId`。本期未进行企业名录关联、资质核验或联系方式补充。
- 页面详情包含供方名称、国家、地址、税号、商品原文、HS、日期、数量、重量、货值、TEU、运输方式、装货港、目的地、提单编号及收货方名称/国家。内部记录/供方编号不再作为页面内容展示；旧基础 API 仍保留原 DTO，接口字段裁剪另需按许可完善。
- 缺失、空白字段返回 null，页面显示“暂无信息”；数值 0 正常显示为 0。编号在 JSON 中使用字符串，避免浏览器丢失 BIGINT 精度。
- 外部文字通过 Vue 文本插值显示，不作为 HTML 执行。数据错误或断网不会回退到演示企业。

## 查询方式

```sql
SELECT TOP (?) <固定字段>
FROM dbo.panjivaMXExport
ORDER BY panjivaRecordId DESC
```

```sql
SELECT TOP (?) <固定字段>
FROM dbo.panjivaMXExport
WHERE panjivaRecordId < ?
ORDER BY panjivaRecordId DESC
```

```sql
SELECT <固定字段>
FROM dbo.panjivaMXExport
WHERE panjivaRecordId = ?
```

每页默认 20 条，最大 50 条；多读 1 条判断是否有下一页，所以单次最多读取 51 条。参数均通过 JDBC 绑定，表名和字段不可由客户端改变。不执行 COUNT、OFFSET、大表 GROUP BY 或 LIKE 扫描，不计算全库总页数。浏览器保留本次浏览的游标历史，可返回上一页；刷新重新从当前最大记录编号开始。

## 接口

- `GET /api/mexico/exports?limit=20`：首屏。
- `GET /api/mexico/exports?limit=20&before=1852582233`：返回严格小于该编号的记录。
- `GET /api/mexico/exports/1852582309`：按编号查询一条记录。

分页返回 `items`、`hasNext`、`nextCursor`、`pageSize`、`order=RECORD_ID_DESC`；不返回虚构的 total。

未登录返回 401；停用账号或禁止的写请求返回 403；非法编号/游标/条数返回 400；记录不存在返回 404；查询或网络失败返回 503；超过每用户每分钟 60 次返回 429。界面提供重试；会话失效会返回登录入口。

# 甲方数据库接入说明

## 当前连接

- 类型：Microsoft SQL Server，SQL 身份验证。
- 服务器：`10.51.247.201:1433`，数据库：`XpressfeedDB`。
- 连接配置与密码：`backend/data/vendor-local.properties`，已排除 Git，权限为 600。
- 使用微软官方 JDBC 驱动 `mssql-jdbc:13.6.0.jre11`。
- 按用户明确确认，仅此内网连接在本地联调时使用 `encrypt=true;trustServerCertificate=true`。生产接入应改用可验证的服务器证书及 `trustServerCertificate=false`。
- 外部数据库连接池为 `VendorReadOnlyPool`，最多 3 条连接；基础浏览/详情查询超时 12 秒，搜索查询超时已按用户要求临时关闭，仍共用原连接池。

账号认证和未来的平台自有记录仍使用本地 MySQL。甲方数据库用于读取企业及贸易数据；未在甲方数据库中创建表、索引或写入任何业务记录。

## 代码入口

- `VendorDataSourceConfig.java`：额外的 SQL Server 数据源及专用 `vendorJdbcTemplate`。
- MySQL 仍为默认数据源，原用户表初始化及注册登录只操作 MySQL。
- `VendorSourceController.java`：`GET /api/data-source/status`，仅当前有效登录用户可以访问；只执行 `SELECT DB_NAME()`，不向页面返回连接密码。
- `scripts/InspectVendor.java`：只读检查工具，从本地配置读取凭据；用于读取表结构及少量样本。输出上限 300 行、查询超时 12 秒，禁止多语句和写入语句。
- 常规自动化测试设置 `vendor.enabled=false`，不会访问甲方数据库。
- `MexicoExportRepository.java`：墨西哥业务数据的三个固定参数化 SELECT：首屏 TOP、主键游标下一页、主键精确详情。
- `MexicoExportService.java` / `MexicoExportController.java`：参数校验、分页边界、登录与账号状态检查、错误转换和每用户每分钟 60 次限流。

## 字段与页面的对应关系

| 页面信息 | 数据来源 | 注意事项 |
| --- | --- | --- |
| 企业名称、地址、城市、成立年、官网、电话 | `ciqCompany` | 不能直接将 Panjiva 企业编号当作 `companyId` |
| 国家 | `ciqCountryGeo` | 包含国家名称、ISO 两位/三位代码 |
| 员工数 | `ciqCompanyData` | 字典中 `companyDataTypeId=35` 为 Number of Employees |
| 行业 | `ciqSimpleIndustry` | 与企业的 `simpleIndustryId` 关联 |
| 供方身份、名称及地址 | 贸易表 `shpPanjivaID/shpPanjivaId`、`shpName` 等 | 国家和进出口方向需按通道分别核定 |
| 贸易商品原文、HS | `goodsShipped`、`hsCode` | 贸易商品描述不等于企业正式产品目录；多编码字段需进一步解析 |
| 贸易日期 | 墨西哥 `shpmtDate`；印尼 `registrationDate` | 不同日期口径不能混为同一统计日期 |
| 数量、单位、重量、货值 | 各贸易表的数量及货值字段 | 墨西哥与印尼字段名称、单位和货值口径不同，不能直接相加 |

缺失的官网、电话、邮箱、报价、MOQ、库存等字段不能使用原型中的演示值填充为真实数据。

## 全库检索与性能边界

最新调整：用户要求临时取消搜索超时，搜索 JDBC 执行和前端等待计时器均已关闭。下文关于 12 秒搜索超时的描述是关闭前的接入与实测记录，其他设置未改。

已检查上述企业、关联和四张贸易表的 `sys.indexes`：目前仅看到企业 ID、关联记录 ID 或贸易记录 ID 的聚集主键索引，未看到产品、HS、日期、供方等检索索引，也未看到列存储索引。

本次应用户要求已接入出口表全表条件查询，商品原文 LIKE、HS 前缀和名称过滤通过参数绑定执行，不限制为本地样本。搜索接口配置 12 秒查询超时、每用户每分钟 12 次、单实例单个并发搜索；不执行全表 COUNT/GROUP BY、OFFSET。超时返回 504，不当作空结果。2026-11-08 复核出口表索引仍仅为 `panjivaRecordId` 的聚集主键；HS `8544` 两页查询成功，关键词 `cable` 与 HS `8544` 的组合出现实际超时，限定 MAXDOP 1 的诊断 SELECT 亦超时，没有据此改变业务 SQL 或甲方索引。

建议与甲方确认：

1. 是否有已发布的供应商检索视图、查询接口或独立检索库。
2. 可用的产品、HS、国家、日期、供方查询索引及允许的查询窗口。
3. `panjivaCompanyCrossRef.identifierTypeId` 的关联规则及有效记录口径。
4. 出口/进口方向与原型 A/B/C 通道的准确映射，以及名录数据是否另有来源。
5. 可公开展示的联系字段、数据许可范围及缓存政策。

当前发现页已恢复原版产品/HS/国家搜索及 A/B/C 通道，A 接入全表条件查询和单条详情；B 本地名录、C 境外贸易线索为待接入入口。结果仍按贸易记录展示，同一供应商可重复，不假称去重企业数或企业排名。稳定低延迟、企业聚合统计及完整 PRD 搜索能力仍需数据与查询方案确认，详见 `供应商搜索与ABC通道.md`。收藏与对比仍为带提示的静态原型。
